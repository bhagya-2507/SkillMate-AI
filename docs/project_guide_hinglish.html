1. Yeh Project Asal Mein Kya Hai? (Overview)

SkillMate AI college students ke liye ek All-in-One AI Study & Placement Platform hai.

Yeh student ka 24/7 Personal AI Tutor bhi hai, Exam Study Planner bhi, Automatic Quiz Tester bhi, aur campus placements ke liye Mock Technical Interviewer & Career Guide bhi hai.

Isme 3 Dedicated Role-Based Dashboards hain:

  • Student Portal: Padhai, quizzes, notes summarize karna, roadmap aur mock interview.
  • Mentor Portal: Teachers/Professors ke liye students ko track karna, study material dena aur feedback likhna.
  • Admin Portal: College management ke liye users manage karna aur CSV/JSON reports export karna.

2. Problem vs Solution (Kyun Banaya Gaya?)

College Student Ki Problem SkillMate AI Ka Solution
Exam pass aa rahe hain, samajh nahi aata kab aur kitna padhein. Smart Study Planner: Subject aur target date dalo, AI daily timetable bana deta hai jo MySQL mein save hota hai.
Topic padh liya par pata nahi exam mein kitne marks aayenge. AI Quiz Generator: AI turant 4 options wale MCQs banata hai, score calculate karta hai aur har question explain karta hai.
100-page ki lambi PDF/PPT notes padhne ka time nahi hota. Notes Summarizer: PDF/TXT upload karo, AI 10 second mein main points, definitions aur exam checklist nikal kar deta hai.
Campus placements/interviews mein technical answers kaise dein? Interview Prep: AI role ke hisab se question puchta hai, answer ko score karta hai (0-100) aur model answer deta hai.
Mentors ko students ki real progress ka pata nahi chalta. Mentor Dashboard: Faculty mentor apne assigned students ka quiz score aur study completion live dekh sakta hai.

3. Technology Stack (Viva Mein Sabse Important)

  • Frontend: React 19 using Vite — Super fast single-page app, responsive SaaS UI, React Router DOM ke saath.
  • Charts & Icons: Recharts (SVG interactive charts for study hours) aur Lucide React (modern icons).
  • Backend: Node.js & Express.js — Asynchronous REST APIs, express-validator for robust form checks.
  • Database: MySQL 8.0 with Sequelize ORM — 15 relational tables with Primary Keys, Foreign Keys, Indexes & Cascades.
  • Security & Auth: JWT (JSON Web Tokens) for session authentication, bcryptjs with 10 salt rounds for password encryption.
  • AI Engine: Official Google Gemini AI SDK (@google/generative-ai) — Backend-only secure integration with fail-safe fallback mode.

6. Viva Ke Top 5 Questions & Best Answers

Q1: Database kahan hai aur kya use kiya hai?
Ans: Humne local MySQL 8.0 database use kiya hai jiska naam skillmate_ai hai. Node.js backend mein Sequelize ORM use kiya hai jo SQL injection se protect karta hai aur 15 relational tables mein Primary Key, Foreign Key aur Cascade delete relationships handle karta hai.
Q2: Passwords secure kaise hain?
Ans: Passwords database mein kabhi plain-text mein save nahi hote. Humne industry-standard bcryptjs use kiya hai jo 10 salt rounds ke saath password ko one-way cryptographic hash mein convert karta hai.
Q3: User Authentication aur Session management kaise kaam karta hai?
Ans: Humne stateless JWT (JSON Web Token) architecture implement ki hai. Jab user login karta hai, server token sign karta hai jisme user ka ID aur Role encrypted hota hai. Frontend par Axios interceptor har protected API call ke saath Authorization: Bearer <token> bhejta hai.
Q4: Kya Student user Admin ke pages ya APIs access kar sakta hai?
Ans: Bilkul nahi! Frontend par React Router ke RoleGuard component se unauthorized routes block hote hain, aur sabse important, Backend par authorize('ADMIN') middleware har protected route par verify karta hai. Agar student admin API call karega toh server seedha 403 Forbidden return karta hai.
Q5: Google Gemini AI kaise integrate kiya hai? Kya API key frontend par visible hai?
Ans: Gemini AI API calls 100% Backend se execute hoti hain using official @google/generative-ai SDK. API key server ke .env file mein secure rehti hai aur frontend par kabhi expose nahi hoti. Agar internet ya API key na ho, toh system crash nahi hota, balki smart educational fallback mode mein gracefully answer karta hai.
